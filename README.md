# COMP3105-MultiClass-PCA-KMeans
Machine Learning assignments from COMP 3105 - Multi-class classification, PCA, K-means

Implementation of core machine learning algorithms from scratch including multi-class logistic regression, PCA, Kernel PCA, and K-means clustering.

## Features
- Multi-class logistic regression with multinomial deviance loss
- Principal Component Analysis (PCA) and Kernel PCA
- K-means and Kernel K-means clustering
- Numerical stability techniques using scipy.special.logsumexp

## Results
- Achieved 94% accuracy on synthetic dataset classification
- Successfully implemented dimensionality reduction with PCA
- Optimal cluster selection at K=4 for generated data
